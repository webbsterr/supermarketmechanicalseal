## Cara publikasi (GitHub Pages)

1. Buat repository baru di GitHub, misalnya `supermarketmechanicalseal.github.io`, set **Public**.
2. Upload SEMUA isi folder ini ke repository (index.html, support.js, folder assets, robots.txt, sitemap.xml, .nojekyll).
3. Buka **Settings → Pages**. Pada *Source* pilih **Deploy from a branch**, branch `main`, folder `/ (root)`. Klik Save.
4. Tunggu 1-2 menit. Website aktif di `https://<username>.github.io/` (atau `https://<username>.github.io/<nama-repo>/`).

## Setelah alamat website final

Ganti alamat `https://supermarketmechanicalseal.github.io/` di file berikut dengan alamat asli:
- `index.html` — tag `canonical`, `og:url`, `og:image`
- `robots.txt` — baris Sitemap
- `sitemap.xml` — tag `loc`

Lalu daftarkan alamat itu di [Google Search Console](https://search.google.com/search-console) dan kirim `sitemap.xml` supaya cepat terindeks Google.

## Struktur

- `index.html` — seluruh halaman website
- `support.js` — runtime yang dibutuhkan halaman
- `assets/` — logo, foto produk, foto toko, video workshop
